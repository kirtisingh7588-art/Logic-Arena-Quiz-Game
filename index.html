Quick Guide

A beginner-friendly map of the concepts used in this project.

01

Logic gates

AND gives 1 only when both inputs are 1. OR gives 1 when at least one input is 1. NOT flips the input.

assign y = a & b;
02

Verilog module

A module describes a digital block. It can define inputs, outputs and the logic connecting them.

module gate(input a, b, output y);
03

Icarus Verilog

iverilog compiles your Verilog source. vvp runs the compiled simulation.

iverilog -o sim.out main.v
04

Testbench

A testbench supplies test inputs and prints results. Use $display to show text in the terminal.

$display("Y=%b", y);
How this website uses Icarus Verilog

The quiz runs in the browser. The Verilog Lab sends code to a local Flask backend, which calls Icarus Verilog to compile and run it. This demonstrates a real connection between the web app and the simulator.
